- `ISA_README.md` — custom instruction-set organization and operation families.

- `VALIDATION_README.md` — verification methodology and gate-level validation.
- `MARKET_POSITIONING_README.md` — product narrative, target application areas, value proposition, and claims that are currently supported by measurement.
- `ROADMAP_README.md` — steps from the current RTL prototype toward a more complete IP/product offering.
